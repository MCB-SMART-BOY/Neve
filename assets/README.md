# Neve Brand Assets

This directory stores the logo and icon variants used by the repository, release artifacts, and packaging metadata.
这个目录保存仓库、发布产物和包管理元数据使用的 logo 与图标资源。

## Primary Assets / 主资源

- `logo.svg`: primary logo with glow / 主版 logo（含光晕）
- `logo-plain.svg`: plain transparent variant / 透明无光晕版
- `logo.ico`: favicon / 浏览器图标

## Size Variants / 尺寸变体

- `logo-64.svg`
- `logo-128.svg`
- `logo-256.svg`
